Bootcamp Microsoft Azure Cloud Native - DIO
Este repositório contém anotações, projetos e desafios desenvolvidos durante o Bootcamp Microsoft Azure Cloud Native, promovido pela DIO em parceria com a Microsoft. O programa é focado em capacitar profissionais para criar, escalar e gerenciar aplicações modernas na nuvem utilizando os principais serviços da plataforma Azure.​
DIO

🚀 Objetivos do Bootcamp
Dominar ferramentas como AKS (Azure Kubernetes Service), Azure Functions, API Management e GitHub Actions.

Aplicar práticas de DevOps e automação no desenvolvimento de aplicações cloud-native.

Integrar soluções de Inteligência Artificial utilizando serviços da Azure.

Preparar-se para certificações Microsoft de nível associate.​

📚 Conteúdo Programático
1. Fundamentos da Plataforma Azure
Introdução ao ambiente cloud da Microsoft.

Conceitos básicos de computação em nuvem.

Arquitetura e principais serviços da Azure.​
DIO

2. Contêineres e Orquestração na Azure
Conceitos de contêineres e Docker.

Orquestração com Azure Kubernetes Service (AKS).

Deploy e gerenciamento de aplicações em contêineres.​

3. Desenvolvimento e Hospedagem de Aplicações Web com o Azure ML
Criação de aplicações web utilizando serviços da Azure.

Integração com Azure Machine Learning.

Hospedagem e escalabilidade de aplicações.​
DIO

4. Gerenciamento e Segurança de APIs na Azure
Implementação de APIs seguras com Azure API Management.

Políticas de segurança e autenticação.

Monitoramento e versionamento de APIs.​
DIO

5. Computação Serverless e Automação na Azure
Criação de funções serverless com Azure Functions.

Automação de processos com GitHub Actions.

Integração contínua e entrega contínua (CI/CD).​
